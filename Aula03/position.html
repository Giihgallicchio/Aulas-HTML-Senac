Aula sobre Position (Posicionamento em CSS)

Position pode ser static, relative, absolute , fixed ou sticky

1. Propriedade Position

É uma Propriedade de posicionamento que trabalha com top, right, bottom e left

Possiveis valores:

  • Statick: Valor padrão, segue o fluxo normal do documento
  • Relative: Posicionado em relação à sua posição original
  • Absolute: Posicionado em relação ao elemento pai
  • Fixed: Posicionado em relação à janela do navegado (viewport)
  • Sticky: Híbrido entre o relative e o fixed

2. Position static

O elemento html segue o fluxo normal da página. esse é o nosso padrão

top, right, bottom e left não têm efeito neste valor

                
                    #caixa {
                        position:static;
                        top: 30px;
                        left: 30px;
                    }

3. Position relative

O elemento continua ocupando seu espaço original no fluxo do documento, mas será deslogado conforme indicado no top, left, bottom e/ou right

                    
                        #demo-relative {
                            position: relative;
                            top: 20px;
                            left: 40px;
                            background-color: lightblue;
                            height: 50px;
                            width: calc(100% - 40px);
                        }

4. Position absolute

O elemento é removido do fluxo normal do documento e passa a se posicionar em relação ao elemento pai

O elemento pai deve ter position relative 

                
                    #container {
                        position: relative;
                        height: 200px;
                        border: 1px dashed grey;
                        width: 100%;
                    }
                    #demo-absolute {
                        position: absolute;
                        top: calc(50% - 25px);
                        right: calc(50% - 50px);
                        background-color: lightblue;
                        height: 50px;
                        width: 100px;
                    }

5. Position fixed

O elemento sai do fluxo normal do documento e será posicionado em relação à janela

                
                    #demo-fixed {
                        position: fixed;
                        bottom: 20px;
                        right: 10;
                        height: 50px;
                        width: 50px;
                        border-radius: 25px;
                        background-color: lightblue;
                    }
