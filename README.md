## Descrição do Projeto

<p>Este repositório reúne atividades, exercícios e conteúdos desenvolvidos durante os estudos de HTML e CSS da Faculdade Senac</p>

<p>O projeto tem como objetivo organizar os códigos desenvolvidos ao longo dos estudos, permitindo acompanhar a evolução dos conhecimentos relacionados à criação e estilização de páginas web.</p>

<p>Os arquivos presentes no repositório abordam diferentes conceitos de HTML e CSS, incluindo a criação de estruturas de páginas, utilização de elementos HTML, aplicação de estilos, organização de conteúdos e desenvolvimento de layouts.</p>

## Organização do Repositório

<p>Os arquivos estão organizados de acordo com as atividades e exercícios realizados durante as aulas, facilitando a consulta e o acompanhamento dos conteúdos desenvolvidos.</p>
